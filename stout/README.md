# 💬 Configurações e Implantação do Stout / Revolt

Esta pasta abriga as configurações, manifestos e arquivos auxiliares para rodar a instância local de **Stout / Revolt** no cluster k3s do Akademus.

---

## 🧭 Estrutura

- `config/`: Variáveis de ambiente e parâmetros dos serviços do Revolt (API, Delta, Autumn, January).
- `k8s/`: Manifestos de implantação em Kubernetes (k3s).
