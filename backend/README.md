# 🐍 Backend do Akademus

Serviço de backend em **Python** utilizando **Flask** e banco de dados **MariaDB**.

---

## 🧭 Estrutura

- `app/`: Código-fonte da aplicação (Blueprints, Models, Services).
- `requirements.txt`: Dependências do ecossistema Python.
- `Dockerfile`: Definição de container para execução nos pods k3s.
